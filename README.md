## 오류 문구

| 상황 | 화면 문구 |
|---|---|
| 401 | 키/권한을 확인해 주세요 |
| 429 | 잠시 후 다시 시도해 주세요 (1초 → 2초 백오프 뒤에도 실패할 때) |
| 500 | 응답을 받지 못했습니다 |
| timeout (30초) | 네트워크를 확인해 주세요 |

## 오류를 직접 내 보기

AI 프록시(w12/ai)를 붙이기 전이라, 가짜 AI가 프록시의 `FORCE_STATUS`처럼 오류를 일부러 낸다.
앱 바 오른쪽 🐞 메뉴에서 고른 뒤 메시지를 보내면 된다.

| 메뉴 | 결과 |
|---|---|
| 정상 응답 | 1.5초 뒤 답이 온다 |
| 401 키/권한 오류 | 바로 오류 말풍선 |
| 429 요청이 너무 많음 (계속) | 1초, 2초 백오프로 두 번 더 시도한 뒤 오류 말풍선 |
| 429 한 번 후 백오프로 성공 | 1초 쉬고 다시 보내서 성공 (오류 말풍선 없음) |
| 500 서버 오류 | 바로 오류 말풍선 |
| timeout 응답 없음 | 30초 동안 타이핑 점, 그 뒤 오류 말풍선 |
